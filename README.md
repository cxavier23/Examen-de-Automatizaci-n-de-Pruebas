# Examen-de-Automatizaci-n-de-Pruebas
Este repositorio contiene un script automatizado en Python utilizando Playwright para realizar búsquedas en el sitio web de Mercado Libre. El script simula la acción de un usuario realizando una búsqueda de Playstation 5 en el sitio, aplicando filtros como "Nuevo" y "Ciudad de México".
